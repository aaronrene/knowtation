# MuseHub Issue Drafts and Filed Reports

This directory holds maintainer-facing MuseHub issue drafts, filed issue bodies,
and contribution evidence for bugs discovered while dogfooding Knowtation.

Use this directory only when the normal MuseHub issue or merge-proposal flow is
blocked, or when a long-form report needs to be staged before filing. The final
source of truth should be the MuseHub issue, GitHub issue, or pull request once
one exists.

These notes do not belong in the sample/user vault. They are repository
maintenance documents.
